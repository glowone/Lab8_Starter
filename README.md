## Graceful Degradation and Service Workers

Graceful degradation and service workers work together to create web apps. Graceful degradation takes care of functionality across all browsers and network conditions while service workers streamline the process by providing an optional enhancement layer. Browsers that support service workers gain offline functionality, caching, and improved performance through intelligent resource interception. With that being said if a browser does not support ServiceWorkers it falls back onto the traditional network requests and still works regardless.
